# apps/web

Package: `@recall-link/web`.

See `AGENTS.md` for monorepo-level commands and conventions.

## Local Commands

```bash
pnpm dev        # vite (port 3000)
pnpm build      # tsc && vite build
pnpm preview
pnpm typecheck  # tsc --noEmit
pnpm test       # vitest run
```

## Code Map

- Entry/providers: `apps/web/src/main.tsx` (TanStack Router + Query + Base UI)
- Routing: `apps/web/src/routes/*` (`createFileRoute(...)`)
- Layout + SSE: `apps/web/src/routes/__root.tsx` (subscribes to `/api/items/events`, patches query cache)
- Data hooks: `apps/web/src/hooks/*` (React Query + some Zustand)
- API layer: `apps/web/src/lib/api-client.ts`
- Styling/theme: `apps/web/src/index.css`

AI support (relevant files):
- Settings UI: `apps/web/src/routes/settings/ai.tsx`
- AI settings management (server-side config): `apps/web/src/hooks/ai-settings.ts`
- Chat flow (SSE streaming from server): `apps/web/src/components/chat/chat-container.tsx`

Shared packages:
 - Web no longer runs LLM calls client-side; all inference happens server-side.
 - Any `@recall-link/ai` alias wiring is legacy and should not be used by new code.

Gotchas:
- `apps/web/src/routeTree.gen.ts` is generated by the TanStack router plugin; don't hand-edit.
- Keep global SSE wiring in `apps/web/src/routes/__root.tsx` (don’t duplicate in feature routes).

## Environment

- `VITE_API_URL` (default `http://localhost:8787`)

## Local Conventions

- Vite alias: `@/*` maps to `apps/web/src/*` (`apps/web/vite.config.ts`).
- Router: use `createFileRoute` + `validateSearch` for typed search params.

## Docs

- Local AI overview: `docs/local-ai.md`

## Anti-Patterns

- Avoid barrel imports that bloat bundles (e.g. `import { X } from "lucide-react"`); prefer direct/targeted imports.
